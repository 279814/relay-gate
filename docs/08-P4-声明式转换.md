# P4 声明式转换实施记录

- 基线：`docs/01-需求与设计.md` §15、§20.5
- 状态：本分支交付转换编译器、请求/响应/SSE 规则核心、shadow/publish/rollback 指针与管理 API

## 已交付

1. `internal/transform` 编译器：拒绝任意脚本迹象、头值 CR/LF、受保护头最终控制、超限正则（RE2）。
2. 请求规则：`set_header` / `delete_header` / `rename_header` / `replace_bytes` / `set_json_pointer`（顶层优先偏移替换）；应用后强制恢复 Authorization 等保护头。
3. 非流式响应：同上 + `set_status`；默认 `fail_open` 回退原始状态/头/body。
4. SSE：按完整事件原子 `sse_match`；`sse_append_end` 标记 synthetic completion。
5. 生命周期：draft → preview → shadow/publish 指针 → rollback；在途请求不改已选版本（指针模型）。
6. shadow 只在副本上算脱敏差异摘要，不改真实请求。
7. 未绑定：`PublishedCompiled` 返回 nil，调用方不得进入转换路径（哈希恒等测试）。
8. 管理 API：`/admin/api/transforms*`、`transform-bindings`、`transform-executions`；main 装配 Registry。
