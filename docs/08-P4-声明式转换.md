# P4 声明式转换实施记录

- 基线：`docs/01-需求与设计.md` §15、§20.5
- 状态：SQLite 持久化、proxy 请求/响应/SSE、管理 UI、JSON Patch、body 模板、Secret 污点已合入；提高执行预算的二次确认审计仍 Deferred

## 已交付

1. `internal/transform` 编译器：拒绝任意脚本迹象、头值 CR/LF、受保护头最终控制、超限正则（RE2）。
2. 请求规则：`set_header` / `delete_header` / `rename_header` / `replace_bytes` / `set_json_pointer`（顶层优先偏移替换）；应用后强制恢复 Authorization 等保护头。
3. JSON Patch 子集：`json_patch_add` / `json_patch_remove` / `json_patch_copy`（RFC 6902；可能重序列化；无 move/test/脚本引擎）。
4. 完整 body 模板：`body_template`（声明式字面量替换；拒脚本；不得删除/改类型/重复顶层 string model）。
5. Secret 引用污点：`secret_ref` 与 `{{SECRET:name}}`；渲染明文记入 `TaintBag`，不得进入预览/差异/执行记录/错误文本；执行记录剥离占位符名。
6. 非流式响应：同上 + `set_status`；默认 `fail_open` 回退原始状态/头/body。
7. SSE：按完整事件原子 `sse_match`；`sse_append_end` 标记 synthetic completion。
8. 生命周期：draft → preview → shadow/publish 指针 → rollback；在途请求不改已选版本（指针模型）。
9. shadow 只在副本上算脱敏差异摘要，不改真实请求。
10. 未绑定：`PublishedCompiled` 返回 nil，调用方不得进入转换路径（哈希恒等测试）。
11. 管理 API：`/admin/api/transforms*`、`transform-bindings`、`transform-executions`；main 装配 Registry。
12. **SQLite 持久化**（schema 6）：`transform_set` / `transform_version` / `transform_binding`；Registry `PersistSink` 在变更时整表快照，启动 `LoadFromPersist`（进程重启后仍可加载已发布绑定）。
13. **proxy 接线**：已发布绑定应用于出站请求、非流式响应与 SSE 事件；未绑定透传；`fail_closed` 在写入客户端前失败时回滚半截头/body 并返回本地错误。
14. **管理 UI**：`transforms.mjs` + `index.html` 转换页（不改脏 `app.js`）。
