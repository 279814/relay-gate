## 已交付

1. **Keyring 文件根**（`internal/keyring`）：`data/secrets/keyring.json`（0600）+ 目录 0700；bootstrap EnsureInitialized / LoadActive。
2. **最近错误首页条 + 弹窗**（§13.2）：`GET /admin/api/recent-errors`；`errors.mjs` + health 卡片/模态（纯文本 `x-text`，不改脏 `app.js`）。
3. **本地一行部署入口**：根目录 `deploy.ps1 -Local` / `./deploy.sh --local` 生成 `.env` 三项凭据并 `go build`。明确拒绝未验证的 `--public`。
4. **三凭据 UI**（`credentials.mjs`）：Master Key 短时查看、Relay Key 轮换/grace/撤销、管理员密码重置、审计列表；均需当次管理员密码。
5. **Master Key 轮换**：Keyring `prepared → db_committed → key_activated → cleaned`；`key_activated` 后 `Store.ActivateMaster` / `Cipher.ActivateMaster` 切换 live Cipher（与 Relay Key 热更新同类，避免只改 Keyring 内存仍用旧钥）；新样本信封 `EncryptEnvelope` 用新 key-id；旧样本信封仍由 retired master 解密（§5.4 不重加密全部大样本；明文 dual-read 仍保留）。
6. **公网 IP HTTPS 状态机**（`internal/acmeip`）：ConfirmIP → ACME challenge → Issue → Validate → Live；失败关闭无明文回退；本地 fake Certbot 单测。
6b. **IP 证书续期可观测**（`internal/acmeip.RenewWatch`）：renew → validate → reload；reload 失败保留旧工作进程并记 `reload_failed_keep_old`；`Snapshot` 暴露 `not_after` / `remaining_hours` / `alert_low_validity`（默认阈值 48h）；本地 fake Renewer/Reloader 单测。**不**声称已签发真实公网证书。
7. **Runtime Controller 扩展**（§4.4 / §12.7 / §13.5）：`runstate` maintenance 叠加态（不覆盖持久化 paused）；Master 轮换 Enter/Exit；未完成轮换启动时保持 maintenance；`GET /admin/api/state` 返回 `effective` + `warmup`；UI 显示维护/暖机且禁止重复凭据轮换。
8. **首次凭据 bootstrap journal**（§12.3）：`relay-gate credentials bootstrap --data-dir <data>`；阶段 `prepared → credentials_persisted → displayed`；`credentials_persisted` 后、`displayed` 前崩溃则撤销未交付的管理员密码与 Relay Key、保留 Master Key 并重新输出三项；Argon2id 哈希写入 `data/secrets/bootstrap-credentials.json`（0600）；长期进程不得重复输出（`ErrBootstrapComplete`）。长期服务仍可用环境变量三项凭据启动（旧部署兼容）；未初始化时错误提示指向 bootstrap CLI。
9. **旧环境变量 migration journal**（§12.8）：`relay-gate credentials migrate --data-dir <data> --db <db>`；需同时具备旧 env（ENCRYPTION_KEY / ADMIN_PASSWORD / RELAY_KEYS）与数据库文件证据，拒绝空 Keyring 静默猜测；阶段 `prepared → imported → completed`；导入 ADMIN_PASSWORD 为 Argon2id、ENCRYPTION_KEY 入 Keyring（保留 SHA-256 派生解密）、RELAY_KEYS 入 credentials 文件；完成后不得再次导入覆盖轮换；日志/stdout 不打印 Secret。
10. **reset-admin**（§12.5）：CLI `relay-gate credentials reset-admin --data-dir <data>` 与管理 API 重置均只替换 Argon2id 哈希并一次性显示新密码；不打印、不可恢复旧密码；重置后撤销其他会话。
11. **登录 / Bearer 读 Argon2id**：热路径校验 `data/secrets/bootstrap-credentials.json` 哈希；环境变量 `ADMIN_PASSWORD` 明文仍兼容（deploy/测试）。
12. **无环境变量启动读 bootstrap/migrate 产物**：`config.Load` 在 `ENCRYPTION_KEY` / `RELAY_KEYS` 环境变量缺省时分别从 `data/secrets/keyring.json`（active Master Key）与 `bootstrap-credentials.json`（`relay_key`）加载；**环境变量优先于文件**（二者同时存在时用 env）；错误信息不回显 Secret 字节；仅设 env 的旧部署仍可启动。**未完成 journal 拒绝启动**：bootstrap journal 非 `displayed`、或 migration journal 非 `completed` 时 `config.Load` 失败（`ErrBootstrapIncomplete` / `ErrMigrationIncomplete`），避免未交付明文凭据已落盘却被长期进程当作已交付。单测见 `internal/config/config_test.go`。
