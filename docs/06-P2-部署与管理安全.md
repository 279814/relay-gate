## 已交付

1. **Keyring 文件根**（`internal/keyring`）：`data/secrets/keyring.json`（0600）+ 目录 0700；bootstrap EnsureInitialized / LoadActive。
2. **最近错误首页条 + 弹窗**（§13.2）：`GET /admin/api/recent-errors`；`errors.mjs` + health 卡片/模态（纯文本 `x-text`，不改脏 `app.js`）。
3. **一行部署入口**：根目录 `deploy.ps1` / `./deploy.sh` → `docker compose up -d --build`；默认发布宿主机端口，访问 `http://IP:port`。无域名 / ACME 邮箱 / 登录 IP 白名单提示。
4. **三凭据 UI**（`credentials.mjs`）：Master Key 短时查看、Relay Key 轮换/grace/撤销、管理员密码重置、审计列表；均需当次管理员密码。
5. **Master Key 轮换**：Keyring `prepared → db_committed → key_activated → cleaned`；`key_activated` 后 `Store.ActivateMaster` / `Cipher.ActivateMaster` 切换 live Cipher；新样本信封用新 key-id；旧样本信封仍由 retired master 解密。
6. **公网 IP HTTPS 状态机**（`internal/acmeip`）：ConfirmIP → ACME challenge → Issue → Validate → Live；本地 fake Certbot 单测。**不是**当前安装教程。
6b. **IP 证书续期可观测**（`internal/acmeip.RenewWatch`）：本地 fake Renewer/Reloader 单测。**不**声称已签发真实公网证书。
7. **Runtime Controller 扩展**：maintenance 叠加态；Master 轮换 Enter/Exit；`GET /admin/api/state` 返回 `effective` + `warmup`。
8. **首次凭据 bootstrap journal**（§12.3）：CLI `credentials bootstrap` 与长期进程 `MaybeBootstrap` 共用；阶段 `prepared → credentials_persisted → displayed`；崩溃恢复规则不变；三项明文只打印一次；环境变量优先。
9. **旧环境变量 migration journal**（§12.8）：`credentials migrate`；完成后不得再次导入覆盖轮换。
10. **reset-admin**（§12.5）：CLI 与管理 API。
11. **登录 / Bearer 读 Argon2id**：哈希优先；`ADMIN_PASSWORD` 明文仍兼容。
12. **无环境变量启动读 bootstrap/migrate 产物**：`config.Load` 从 keyring / bootstrap-credentials 加载；env 优先；未完成 journal 拒绝启动（incomplete bootstrap 由启动前 `MaybeBootstrap` 先恢复）。
13. **删除登录 IP 白名单部署路径**：去掉 Caddy/nginx `RELAY_ALLOW_IPS`；管理登录仅保留失败退避。保留可选 SMTP 告警（空配置 no-op）。
