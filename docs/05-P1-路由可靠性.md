## 已交付

1. **RecoveryGate**（`internal/health/recovery_gate.go`）：每 Route 半开 single-flight，独立于 `max_concurrency`；`max_concurrency=0` 时仍最多一个 half-open Attempt。半开放行路径同时占 RecoveryGate 与普通并发额度。占位后若 handler 在 transform / commit / 观察路径上 panic，`forwardWithRetry` / `count_tokens` 经 `defer Release` 归还额度与闸（§9.4）；不在重试环内 recover，避免 panic 再开一次上游 Attempt。
2. **RetryPolicy**（`settings.retry_policy`）：`safe` / `balanced`（默认）/ `aggressive`。Safe 仅在无响应头且无已获连接证据时允许换站；Balanced 保持原可重试集合；Aggressive 把提交前首字节等待扩大到 `real_first_byte_sec`（PeekWait），并在 UI 明示延迟响应头与重复执行风险。
3. **DuplicateRisk**：`request_log` 持久化 `duplicate_risk` / `retry_reason` 列（schema 4）。
4. **重复 model**：顶层重复 `model` 键 → 400，零上游调用；尾部非法 JSON 仍不由网关代上游拒绝（§3.3）。
5. **StateRecovering**：合成成功使 dead→recovering；真实成功使 dead/recovering→alive；recovering 选路须占 RecoveryGate（Lazy 真实流量 single-flight）。
6. **SemanticInvalidator**：§9.2 统一清 RouteHealth / RecoveryGate / Capability / 调度预占（学习引用接口已留）。
7. **count_tokens 多 Route**：supported 优先 → 临时失败换下一个 supported → 一个 unknown 观察 → 本地估算。
8. **full_url 迁移审核**：`POST /admin/api/upstream-endpoints/{id}/confirm-review` + `migration.mjs`（须显式 `url_override`，不静默猜测）。
