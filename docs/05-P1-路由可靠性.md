# P1 路由可靠性实施记录

- 基线：`docs/01-需求与设计.md` §9、§10.3、§11、§19.2、§20.2
- 状态：本分支交付 P1 核心门禁；细节以本文「已交付 / Deferred」为准

## 已交付

1. **RecoveryGate**（`internal/health/recovery_gate.go`）：每 Route 半开 single-flight，独立于 `max_concurrency`；`max_concurrency=0` 时仍最多一个 half-open Attempt。半开放行路径同时占 RecoveryGate 与普通并发额度。
2. **RetryPolicy**（`settings.retry_policy`）：`safe` / `balanced`（默认）/ `aggressive`。Safe 仅在无响应头且无已获连接证据时允许换站；Balanced 保持原可重试集合；Aggressive 不收窄（后续可扩宽首字节窗口）。
3. **DuplicateRisk**：重试 Attempt 的 `RequestLog` JSON 字段记录 `duplicate_risk` / `retry_reason`（内存与 API 形状；DB 列留待 schema 扩展）。
4. **重复 model**：顶层重复 `model` 键 → 400，零上游调用；尾部非法 JSON 仍不由网关代上游拒绝（§3.3）。
